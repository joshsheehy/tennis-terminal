# Claude Code Instructions

Always commit and push directly to the `main` branch. Do not create feature branches or pull requests.

## Links

The canonical production URL is `https://tenniscuts.com` (the app is served there; the `*.up.railway.app` host is just the underlying Railway deployment name and should not be used in anything user-facing). Whenever giving the user API endpoints or action steps, always format every URL as a clickable markdown hyperlink using the `https://tenniscuts.com` base. Never list a bare path — always provide the full URL as `[label](url)`.
